### Is my data safe?
All information you save stays within your local instance or your chosen server. The platform uses standard encryption methods for data in transit.

### Can I share files easily?
Yes. Drag and drop any file into a chat or a project card. The software uploads the file so others can download it immediately.

### What happens if I lose my connection?
Deskive saves your changes locally. It syncs the data once you reconnect to the network. You can continue to view existing information while offline.

### Can I use this for personal work?
Yes. Although designed for teams, the task management and note tools function well for individual project planning.

## 📖 Using the Workspace

The user interface follows a standard layout to help you navigate your work.

* Left Sidebar: Access your different channels, direct messages, and tools.
* Top Bar: Use the search field to find specific files, tasks, or past messages across your entire workspace.
* Central Window: View your active chat, the board you selected, or the document you currently edit.
* Right Sidebar: View details of a selected task, a list of team members in a channel, or upcoming calendar events.

When you start the app, log in with your credentials. If you are new to the platform, create a workspace by choosing a name and inviting teammates via their email addresses. Each workspace acts as a silo for your team, keeping information separated from other projects.

For navigation, use the keyboard shortcuts displayed in the settings menu to move faster between chat and projects. You can toggle between light and dark modes in the user preferences to reduce eye strain during extended work hours.

The settings menu also allows you to manage notifications. Adjust your alert settings to receive pings for urgent messages or silence notifications during deep focus hours.
